composer -V
node -v

💡 Tips: Jika ada yang belum terinstall, download dari website resmi masing-masing software.

📦 Instalasi Dependencies

1 Clone atau Download Project

Jika menggunakan Git:

git clone [URL_REPOSITORY]
cd [NAMA_FOLDER_PROJECT]

Atau extract file ZIP project ke folder yang diinginkan.

2 Install Dependencies PHP (Composer)

Jalankan perintah berikut di root folder project:

composer install
Proses ini akan menginstall semua package PHP yang dibutuhkan Laravel. Tunggu hingga selesai (bisa memakan waktu beberapa menit).
3 Install Dependencies JavaScript (NPM)

Jalankan perintah berikut:

npm install

Atau jika menggunakan PNPM:

pnpm install
⚠️ Perhatian: Project ini menggunakan React, Vite, dan Tailwind CSS. Proses instalasi mungkin memakan waktu 5-10 menit tergantung koneksi internet.

⚙️ Konfigurasi Environment

1 Copy File Environment

Buat file .env dari template:

copy .env.example .env

Untuk Linux/Mac:

cp .env.example .env
2 Generate Application Key

Jalankan perintah:

php artisan key:generate
Perintah ini akan menggenerate key unik untuk aplikasi dan menyimpannya di file .env
3 Konfigurasi Database

Buka file .env dan sesuaikan konfigurasi database:

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=nama_database_anda
DB_USERNAME=root
DB_PASSWORD=password_anda
⚠️ Penting: Pastikan nama database, username, dan password sesuai dengan konfigurasi MySQL Anda.
4 Konfigurasi Lainnya (Opsional)

Sesuaikan konfigurasi lain di file .env jika diperlukan:

APP_NAME="Nama Aplikasi Anda"
APP_URL=http://localhost:8000
APP_ENV=local
APP_DEBUG=true

🗄️ Setup Database

1 Buat Database

Buka MySQL melalui command line atau phpMyAdmin, lalu buat database baru:

mysql -u root -p

Kemudian jalankan query:

CREATE DATABASE nama_database_anda CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
EXIT;
2 Jalankan Migration

Kembali ke terminal project dan jalankan:

php artisan migrate
Perintah ini akan membuat semua tabel yang dibutuhkan aplikasi di database.
3 Seed Database (Opsional)

Jika ingin mengisi database dengan data dummy untuk testing:

php artisan db:seed
✅ Berhasil! Database sudah siap digunakan.

🚀 Menjalankan Aplikasi

Metode 1: Menjalankan Secara Terpisah

1 Jalankan Laravel Development Server

Buka terminal pertama dan jalankan:

php artisan serve

Server akan berjalan di: http://localhost:8000

2 Jalankan Vite Development Server

Buka terminal kedua (jangan tutup terminal pertama) dan jalankan:

npm run dev

Atau dengan PNPM:

pnpm dev
Vite akan compile asset (CSS, JavaScript, React) secara real-time dengan hot reload.

Metode 2: Menjalankan Semua Sekaligus (Recommended)

1 Gunakan Composer Script

Project ini sudah dikonfigurasi untuk menjalankan semua service sekaligus:

composer dev
Perintah ini akan menjalankan:
  • Laravel development server
  • Queue worker
  • Log viewer (Pail)
  • Vite development server

Mengakses Aplikasi

Buka browser dan akses:

http://localhost:8000
🎉 Selamat! Aplikasi Anda sudah berjalan!

Build untuk Production

Ketika siap deploy ke production, build asset dengan:

npm run build

Kemudian optimize Laravel:

php artisan config:cache
php artisan route:cache
php artisan view:cache

🔧 Troubleshooting

Problem: Composer Install Gagal

Solusi:

  • Pastikan PHP versi 8.2 atau lebih tinggi
  • Aktifkan extension yang dibutuhkan di php.ini
  • Jalankan: composer update
  • Clear cache: composer clear-cache

Problem: NPM Install Error

Solusi:

  • Hapus folder node_modules dan file package-lock.json
  • Jalankan ulang: npm install
  • Atau gunakan: npm install --legacy-peer-deps
  • Coba gunakan PNPM: pnpm install

Problem: Migration Gagal

Solusi:

  • Pastikan database sudah dibuat
  • Cek konfigurasi database di file .env
  • Pastikan MySQL service berjalan
  • Test koneksi: php artisan db:show

Problem: Port 8000 Sudah Digunakan

Solusi:

Gunakan port lain:

php artisan serve --port=8080

Problem: Vite Error atau Asset Tidak Load

Solusi:

  • Pastikan npm run dev berjalan
  • Clear cache browser (Ctrl+Shift+Delete)
  • Hapus folder public/build
  • Restart Vite server

Problem: Permission Denied (Linux/Mac)

Solusi:

chmod -R 775 storage bootstrap/cache
chown -R $USER:www-data storage bootstrap/cache

Problem: Class Not Found

Solusi:

composer dump-autoload
php artisan clear-compiled
php artisan cache:clear
php artisan config:clear
💡 Tips Debugging:
  • Cek log error di storage/logs/laravel.log
  • Aktifkan debug mode: APP_DEBUG=true di .env
  • Gunakan: php artisan about untuk info sistem
